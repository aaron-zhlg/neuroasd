# PR #30 + 分界线修正（记录，未被接受）

在 PR #30 的模型上只改了训练内部定分界线的两处：

1. 训练内部交叉验证时，标准化只用该内层的训练部分（原来用了整个训练集，含内层验证部分）。
2. 组合那一步改为交叉拟合：定分界线用的组合分数不再"在同一批行上训练又打分"。

| | 留一站点 ASD / 对照 / AUC | 留一机构 ASD / 对照 / AUC | 锁定 323 人 ASD / 对照 / AUC |
|---|---|---|---|
| PR #30 | 74.3 / 75.4 / 0.810 | 74.7 / 73.4 / 0.790 | 68.2 / 67.1 / 0.756（第 5 次，PR #29） |
| 本版本 | 68.5 / 77.7 / 0.812 | 62.1 / 77.0 / 0.791 | 66.2 / 67.8 / 0.760（第 6 次） |

结论：AUC 不变；修正后开发集上的分界线变保守，说明之前 ASD recall 的部分提升来自训练内部分数偏乐观。
锁定集上两者平均基本不变（67.0 vs 67.7），对照 recall 仍只有约 68%：新机构上对照 recall 下降主要来自站点差异，
不是训练内部的这两个小问题。按 "ASD recall 必须提高" 的规则未被接受。

复现：`uv run python -m autoresearch.trial --name fixcut-pr30 --stage loso-site`（以及 screen、loso-institution）。
