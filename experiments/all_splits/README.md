# 各模型在各种测法下的分数

每格是 **ASD recall / 对照 recall / AUC**，各折平均。所有分数都是"每个测试者单独判断"：
不用测试站点其他人的分数，也不按测试站点校准。

## 测法

| 测法 | 怎么测 | 测试的人见没见过 |
|---|---|---|
| 随机 10 折 | 1,120 名开发集受试者随机分 10 份，只按 ASD/对照比例分层；每次 9 份训练、1 份测试，轮 10 次 | 训练里有同一站点的人（多数论文的测法） |
| 按站点分层 10 折 | 同上，但每一份里各站点的比例保持一致 | 训练里有同一站点的人 |
| 留一站点 | 33 个站点轮流拿出 1 个做测试，其余训练 | 测试站点完全没见过 |
| 留一机构 | 同一机构的多个站点（如 NYU 的 ABIDE I 和 II）一起拿出，16 个机构轮流 | 测试机构完全没见过，比留一站点更严 |
| 锁定 323 人 | 7 个机构（PITT、TRINITY、IP_1、EMC_1、CALTECH、LEUVEN、UCLA）用固定随机种子选出，自动实验从未见过；用全部 1,120 人训练一次，测这 323 人，取 7 个机构的平均 | 测试机构完全没见过，也从没参与选方案；最干净 |

前四种都在 1,120 名开发集受试者上，自动实验在这些人上挑方案，所以分数偏乐观。
锁定 323 人只测过 4 次，每次都有记录（`outputs/autoresearch/holdout_log.jsonl`）。

## 论文（都是 ABIDE I）

| 论文 | 测法 | ASD recall / 对照 recall / AUC |
|---|---|---|
| BrainMass 2024 | 随机 70/15/15 划分，重复 10 次；先在 4.7 万人上预训练 | 74.3 / 71.9 / 不报 |
| BrainNetTF 2022 | 随机划分 | 72.5 / 69.3 / 约 0.80（凭记忆，未重新核对表格） |
| ASD-DiagNet 2019 | 随机 10 折 | 68.3 / 72.2 / 不报 |
| Heinsfeld 2018 | 随机 10 折 | 74 / 63 / 不报 |
| Heinsfeld 2018 | 留一站点 | 69 / 62 / 不报 |
| Abraham 2017 | 跨站点 | 61（实际按 precision 算）/ 72.3 / 不报 |

## 结论

- **随机划分**：PR #24、PR #25 的 ASD recall 和对照 recall 都高于所有论文，AUC 也高于 BrainNetTF。
- **新站点**：在 1,120 人上的留一站点 / 留一机构两项都高于 Heinsfeld 和 Abraham；
  在锁定的 323 人上和它们大致持平（ASD recall 与 Heinsfeld 相当，对照 recall 低于 Abraham）。
- **数据不同**：这里是 ABIDE I+II、DCAN 预处理，论文大多只用 ABIDE I。

每个模型的逐折结果在 `all_splits.json`（这里的子目录，以及 `outputs/autoresearch/all_splits/`）。
