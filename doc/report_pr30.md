# PR #30 模型报告：和论文的公平对比 + 严格测试

模型代码就是 [PR #30](https://github.com/aaron-zhlg/neuroasd/pull/30)（`neuroasd/model.py`，没有改动）。
本报告新增的只有测试脚本和结果。

## 一句话结论

- **按论文同样的随机划分方法测，我们和所有论文持平或更高。**
  - 随机 10 折：自闭症检出率 74.1%、对照检出率 73.8%，两项都明显高于 ASD-DiagNet 和 Heinsfeld。
  - 按 BrainNetTF、BrainMass 的随机划分方法测：
    - 把对照检出率调到和论文一样，自闭症检出率和它们持平或略高（74.3 对 72.5，74.2 对 74.3）。
    - 直接用模型自己的分界线时，对 BrainMass 的自闭症检出率低（68.0 对 74.3），但对照检出率更高。
- **论文用的都是随机划分。** 测试的人和训练的人来自同样的扫描站点，这种测法偏容易。
- **在更严格的测试下（测试站点训练时完全没见过），我们的分数也列出来了。**
  - 这类测试大多数论文没做。
  - 在自动实验从没见过的 7 个机构（323 人）上：自闭症检出率 68.2%、对照检出率 67.5%、AUC 0.756。

## 数据和模型

- 数据：ABIDE I + II，DCAN 预处理，1,443 人。
  - 其中 323 人（7 个机构）锁定不用，只做最终测试。
  - 下面的"随机划分"测试都在其余 1,120 人上做（475 名自闭症）。
- 每个人单独判断：不用测试集其他人的信息，不按测试站点校准，和论文一样。
- 模型由几部分组成：
  - 四套脑区划分（Gordon、HCP、Power、Markov），每套都算脑连接矩阵，先做收缩估计，再投到切空间。
  - 只用训练数据挑出差别最大的连接，再用逻辑回归和梯度提升树打分，最后组合成一个分数。
  - 分界线只用训练数据来定（训练数据内部交叉验证时，对照检出率定在 73%）。
  - 所有参数都只用训练数据学，测试的人只作为输入。

## 1. 公平对比：和论文用同样的随机划分方法

论文的划分方法（都核对过原文）：

| 论文 | 数据 | 划分方法 |
|---|---|---|
| ASD-DiagNet 2019 | ABIDE I，1,035 人 | 随机 10 折 |
| Heinsfeld 2018 | ABIDE I，1,035 人 | 随机 10 折（数字用 ASD-DiagNet 论文里的重跑结果，Heinsfeld 原文没能打开核对） |
| BrainNetTF 2022 | ABIDE，1,009 人 | 随机 70% 训练、10% 验证、20% 测试，按站点分层，重复 5 次 |
| BrainMass 2024 | ABIDE I，1,084 人；另外在 4.7 万人上预训练 | 随机 70% 训练、15% 验证、15% 测试，按站点分层，重复 10 次 |

我们用完全一样的划分方法和重复次数。有一点我们吃亏：验证集我们不用，只拿 70% 训练。

### 1a. 直接用模型自己的分界线

数字是各次测试的平均值（± 标准差）。

| 划分方法 | 谁 | 自闭症检出率 | 对照检出率 | 准确率 | AUC |
|---|---|---|---|---|---|
| 随机 10 折 | **我们** | **74.1 ± 6.9** | **73.8 ± 5.8** | **73.9** | **0.819** |
| | ASD-DiagNet | 67.8 | 72.8 | 70.1 | 没报 |
| | Heinsfeld | 69.3 | 61.0 | 65.4 | 没报 |
| 70/10/20，5 次 | **我们** | 72.4 ± 8.1 | **71.5 ± 6.2** | **71.9** | 0.796 |
| | BrainNetTF | 72.5 | 69.3 | 71.0 | 0.802 |
| 70/15/15，10 次 | **我们** | 68.0 ± 6.6 | **75.8 ± 6.6** | 72.5 | 0.804 |
| | BrainMass | 74.3 | 71.9 | 72.8 | 没报 |

### 1b. 把对照检出率调到和论文一样，再比自闭症检出率

两种方法的自闭症检出率和对照检出率此消彼长，只比一项不公平。
这里用同一批测试分数，把分界线挪到论文的对照检出率，再看能找出多少自闭症。
这是"同样标准下谁更准"的比较，不是实际使用时的分界线（分界线是看了测试分数才定的）。

| 划分方法 | 论文（对照检出率） | 论文的自闭症检出率 | 我们的自闭症检出率 |
|---|---|---|---|
| 随机 10 折 | ASD-DiagNet（72.8） | 67.8 | **76.5** |
| 随机 10 折 | Heinsfeld（61.0） | 69.3 | **86.3** |
| 70/10/20，5 次 | BrainNetTF（69.3） | 72.5 | **74.3** |
| 70/15/15，10 次 | BrainMass（71.9） | 74.3 | 74.2（持平） |

### 1c. 只用 ABIDE I（附录）

如果只用 ABIDE I 的 789 人（论文大多只用 ABIDE I），训练的人少了一半左右，分界线偏向判"对照"：
- 自闭症检出率：随机 10 折 67.6，70/10/20 是 64.9，70/15/15 是 58.5。
- 对照检出率：分别是 74.4、84.5、83.1。
- AUC：0.789、0.837、0.819。

把对照检出率调到和论文一样后，自闭症检出率分别是：
- 69.1（对 ASD-DiagNet 的 67.8）
- 79.0（对 Heinsfeld 的 69.3）
- 80.3（对 BrainNetTF 的 72.5）
- 73.7（对 BrainMass 的 74.3）

完整表格见 `experiments/pr30_release/paper_compare_abide1.md`。

## 2. 严格测试：测试站点训练时没见过

论文的随机划分，测试的人和训练的人来自同一批扫描站点，模型可以"认站点"，分数偏高。
下面三种测法更严格，大多数论文没有做：

| 测法 | 怎么测 | 自闭症检出率 | 对照检出率 | AUC |
|---|---|---|---|---|
| 留一站点 | 1,120 人，24 个站点轮流拿出 1 个做测试 | 74.3 | 75.4 | 0.810 |
| 留一机构 | 1,120 人，同一机构的站点一起拿出，16 个机构轮流 | 74.7 | 73.4 | 0.790 |
| **锁定 323 人** | 7 个机构，用固定随机种子选出，自动实验从没见过；用 1,120 人训练一次，测这 323 人（7 个机构平均） | **68.2** | **67.5** | **0.756** |

- 留一站点和留一机构是在自动实验反复挑方案的 1,120 人上测的，所以偏乐观。
- 最干净的是锁定 323 人。锁定集一共看过 7 次，每次都有记录（`experiments/pr30_release/holdout_log.jsonl`）。这次是第 7 次，测的就是 PR #30 本身。
- 可以对比的论文（都只用 ABIDE I）：
  - Abraham 2017 留一站点：自闭症检出率 61.0、对照检出率 72.3、准确率 66.8。论文里"敏感度"一列的定义有歧义，原文的说法像是精确率。
  - Heinsfeld 2018 留一站点：准确率约 65%，原文没能核对。
- 在锁定的新机构上，我们的自闭症检出率比 Abraham 高 7 个点，对照检出率低 5 个点，平均下来大致持平略高。

## 3. 模型主要看哪些脑连接（弦图）

做法：
- 用随机 10 折的"折外分数"：每个人的分数来自一个没见过这个人的模型。
- 算每条 Gordon 脑区连接的强度和分数的相关。连接强度和分数都先在站点内部减去平均值，避免把站点差异当成连接差异。
- 红色：在被判为自闭症的人里更强。蓝色：更弱。

![前 100 条连接](https://raw.githubusercontent.com/aaron-zhlg/neuroasd/release/pr30-model/experiments/pr30_release/chord/chord_rois.png)

![前 1% 连接（618 条）按脑网络汇总](https://raw.githubusercontent.com/aaron-zhlg/neuroasd/release/pr30-model/experiments/pr30_release/chord/chord_networks.png)

| 脑网络对 | 前 1% 里的条数 | 更弱 / 更强（自闭症方向） | 富集倍数 |
|---|---|---|---|
| 手部运动区 内部 | 126 | 126 / 0 | 17.9 倍 |
| 口部运动区 – 手部运动区 | 79 | 79 / 0 | 26.0 倍 |
| 默认网络 内部 | 54 | 54 / 0 | 6.6 倍 |
| 手部运动区 – 皮层下 | 42 | 0 / 42 | 5.8 倍 |
| 听觉 – 手部运动区 | 34 | 34 / 0 | 3.7 倍 |
| 默认网络 – 背侧注意 | 24 | 0 / 24 | 1.8 倍 |
| 听觉 – 皮层下 | 19 | 0 / 19 | 4.2 倍 |

- **最明显：躯体运动网络内部的连接，在判为自闭症的人里更弱**（手部、口部运动区之间，及它们和听觉区之间）。
- **默认网络内部连接更弱**，和以往自闭症研究里"默认网络连接减弱"的报告一致。
- **皮层下（丘脑、尾状核、小脑）和运动区、听觉区的连接更强。** 之前 GNN 模型的弦图里也看到"皮层下–听觉更强"。
- 注意：这是模型分数和连接的相关，不代表因果；头动等因素也可能影响运动区的连接。

## 4. 局限

- 1,120 人上的分数偏乐观：自动实验在这些人上试了几十轮，只保留最好的。最可信的是锁定 323 人的分数。
- 预处理不同：我们用 DCAN，论文大多用 CPAC。
- 论文数字来自 arXiv 版本（BrainMass、BrainNetTF、ASD-DiagNet、Abraham），期刊版可能略有不同；Heinsfeld 原文没能打开。
- 模型自己的分界线在训练数据少时不准，会偏向判"对照"（只用 ABIDE I 时最明显），这是下一步要改的地方。

## 复现

```bash
# 论文的随机划分方法（两期数据 1,120 人）
uv run python -m autoresearch.loop.paper_protocols --data dev --protocols random-10fold brainnettf brainmass \
    --out-dir experiments/pr30_release/paper_protocols_dev
# 只用 ABIDE I
uv run python -m autoresearch.loop.paper_protocols --data abide1 --protocols random-10fold brainnettf brainmass \
    --out-dir experiments/pr30_release/paper_protocols
# 对比表
uv run python -m scripts.paper_compare experiments/pr30_release/paper_protocols_dev/paper_protocols.json
# 锁定 323 人
uv run python -m autoresearch.loop.final_holdout --name pr30 --note "..."
# 弦图
uv run python -m scripts.plot_chord_pr30 --out-dir experiments/pr30_release/chord
```

结果文件都在 `experiments/pr30_release/`：

| 文件 | 内容 |
|---|---|
| `paper_protocols_dev/`、`paper_protocols/` | 每次测试每个人的分数 |
| `all_splits_1120.json` | 随机 10 折、按站点分层 10 折 |
| `loso_result.json` | 留一站点、留一机构 |
| `holdout_log.jsonl` | 锁定集 7 次测试记录 |
| `chord/` | 弦图和连接表 |

运行时的 git 记录是 `autoresearch/recall-objective`，当时 `neuroasd/` 的代码和 PR #30 逐字相同。
